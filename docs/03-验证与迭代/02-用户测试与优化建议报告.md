# 02 用户测试与优化建议报告（10 人内测）

> 时间：2025.11.01 – 2025.11.15 ｜ 样本：10 人（初中 4 / 高中 4 / 大学 2） ｜ 数据：埋点 + 问卷 + 访谈

---

## 一、内测结果总览

| 指标 | 目标 | 实际 | 是否达标 |
| --- | --- | --- | --- |
| CSAT 均分（1–5） | ≥ 4.0 | 4.2 | ✅ |
| NPS | ≥ 30 | 40 | ✅ |
| 讲解后同型题正确率 | ≥ 80% | 82% | ✅ |
| 前→后测迁移正确率提升 | ≥ 15% | 21% | ✅ |
| 错因定位准确率（专家复核） | ≥ 85% | 78% | ❌ 未达标 |
| 拍照识别成功率（手写） | ≥ 70% | 66% | ❌ 未达标 |
| 讲解生成耗时 P90 | ≤ 5s | 4.6s | ✅ |
| 任务闭环成功率 | ≥ 85% | 88% | ✅ |
| 直接复制答案率 | ≤ 10% | 14% | ⚠️ 略超 |

## 二、主要发现

### 2.1 亮点（用户认可的部分）
1. **"每步都有为什么"** 是用户最买账的设计（8/10 主动提及），显著优于"豆包/作业帮"；
2. **错因分析**对"小雨"类用户价值最高：6/10 表示"第一次知道原来我错在符号这一步"；
3. 讲解深度三档中，"标准"档使用率 60%，"基础"档 30%，"进阶"档 10%——符合预期分层。

### 2.2 问题与根因

| 问题 | 根因分析 | 涉及功能 |
| --- | --- | --- |
| **Q1 错因定位准确率 78%** | LLM 对"过程很乱/多步错误"的输入，难以准确对齐到具体步骤；错因标签体系与真实错误形态有 gap | F3 |
| **Q2 手写拍照识别 66%** | 手写体 OCR 基线弱，连笔、草稿纸反光、多行公式识别差 | F1 |
| **Q3 直接复制答案率 14%** | 答案折叠可一键展开，缺少"先想再看"的强制/激励 | F5 |
| **Q4 高三/大学生希望"追问"** | 讲解是单向输出，无法就某一步继续追问（"为什么这里能交换？"） | F2/F3 |
| **Q5 引导模式呼声高但 MVP 未做** | R5 被延后，但 4/10 用户主动提到想要"提示式"讲法 | 新 |

## 三、优化建议（按优先级）

| 优先级 | 建议 | 对应问题 | 预估成本 |
| --- | --- | --- | --- |
| P0 | 错因分析增加"步骤对齐"：让学生先勾选"我写的这一步对应标准过程的哪一步"，再定位错因，提升准确率 | Q1 | 中 |
| P0 | 错因标签体系扩展为 8 类，并给出每类的典型例句 | Q1 | 低 |
| P0 | 手写识别优化：接入更强 OCR 模型 + 拍照引导框（"请对准题目、光线充足"） | Q2 | 高 |
| P1 | 答案折叠改为"默认隐藏 + 展开需二次确认（想一想再对答案）" | Q3 | 低 |
| P1 | 讲解支持"追问某一步"：点击步骤可继续问"为什么"，AI 局部展开 | Q4 | 中 |
| P1 | 增加"引导模式"（苏格拉底）作为讲解深度第 4 档（灰度） | Q5 | 中 |
| P2 | 错题本 V1：错因标签自动沉淀，支持按标签复习 | 远期 | 高 |

## 五、结论

MVP 的核心假设——"**用户需要看得懂的过程 + 按思路纠错**"——在 10 人内测中得到验证（CSAT 4.2、迁移正确率提升 21%）。
最需补齐的两块短板是 **错因定位准确率（78%→目标 85%+）** 与 **手写识别（66%→目标 70%+）**，已列入 V1.1 P0。
产品整体具备继续投入的价值：差异化卖点（错因分析）被用户认可，且与竞品形成明显区隔。

# 01 评估指标体系（内测用）

> 用于 10 人内测的数据采集，同时服务于 MVP 上线后的埋点设计。
> 评估对象：满意度（主观）、解题正确率（客观）、效率、可用性、学习迁移。

---

## 一、指标体系总览

| 维度 | 指标 | 定义/计算方式 | 采集方式 | 目标值 |
| --- | --- | --- | --- | --- |
| **满意度** | CSAT 满意度 | "你愿意向同学推荐这个功能吗？" 1–5 分（≥4 计为满意） | 内测问卷 | ≥ 4.0 均分 |
| | NPS 推荐度 | 0–10 分，Promoter 占比 - Detractor 占比 | 内测问卷 | ≥ 30 |
| **解题正确率** | 讲解后正确率 | 用户看完讲解后独立重做同型题的正确率 | 平台自动记录 + 人工判分 | ≥ 80% |
| | 讲解正确率 | 平台给出的最终答案正确率（抽检） | 人工抽检 20% 样本 | ≥ 95% |
| | 错因定位准确率 | 错因定位与人工专家判断一致的占比 | 专家复核 | ≥ 85% |
| **效率** | 讲解耗时 | 生成讲解耗时（秒） | 埋点 | P90 ≤ 5s |
| | 任务完成时长 | 从拍照到完成 1 道同类题的总时长 | 埋点 | 均值 ≤ 10min |
| **可用性** | 任务成功率 | 未求助完成"拍照→讲解→错因→同类题"闭环的占比 | 任务操作记录 | ≥ 85% |
| | 关键路径流失 | 各步骤间流失率 | 埋点漏斗 | 步骤间流失 ≤ 30% |
| **学习迁移** | 迁移正确率 | 新题（同类不同数据）正确率提升幅度 | 前后测对比 | 相对提升 ≥ 15% |
| **信任/合规** | 直接复制答案率 | 未看讲解直接复制答案的会话占比 | 埋点 | ≤ 10%（越低越好） |

---

## 二、内测实验设计（10 人）

### 2.1 被试
- 从 15 人访谈样本中邀请 10 人（初中 4、高中 4、大学 2），覆盖三档成绩。

### 2.2 流程
```
前测(10min)：完成 2 道对应年级的同类题（记录正确率基线）
→ 使用 Demo 完成 3 个任务（拍照识题 / 分步讲解 / 错因分析+同类题）
→ 后测(10min)：完成 2 道新题（同类不同数据）
→ 访谈(15min) + 问卷（CSAT / NPS / SUS）
```

### 2.3 三个标准任务
| 任务 | 内容 | 观察点 |
| --- | --- | --- |
| T1 | 用 Demo 拍照识别 1 道题并确认文本 | 识别成功率、编辑成本 |
| T2 | 看完分步讲解后口头复述"这道题为什么这么做" | 是否"看懂" |
| T3 | 故意提交一个错误答案，完成错因分析并做 1 道同类题 | 错因定位质量 |

---

## 三、数据采集工具

1. **平台埋点**：识别成功率、讲解生成成功/耗时、答案折叠点击率、错因分析使用率；
2. **问卷**：CSAT（各功能）、NPS、SUS 系统可用性量表；
3. **访谈**：半结构化，围绕"哪一步最让你困惑""错因分析是否说到点子上"展开；
4. **专家复核**：数学老师/研究生复核错因定位与讲解正确性样本。

## 四、数据分析方法

- 前后测正确率：配对样本 t 检验（n=10，显著性 α=0.05）；
- 流失分析：漏斗各步骤转化率；
- 定性编码：访谈文本按"困惑点/亮点/改进建议"三分类编码，统计提及频次。

# 访谈提纲（半结构化一对一访谈）

> 目的：了解中学生/大学生使用 AI 工具学习数学的现状、痛点与期望。
> 方式：一对一线上/线下访谈，45–60 分钟/人；全程录音（征得同意），结束后 24h 内完成转录与编码。
> 对象筛选：覆盖 初中（5 人）、高中（5 人）、大学（5 人），兼顾 成绩中等/偏科/绩点优秀 等不同水平。

---

## 0. 开场（5 min）

- 自我介绍与项目说明：我们正在做一款 AI 数学学习助手，想了解你平时是怎么学数学、怎么用 AI 工具的。
- 告知：访谈约 45–60 分钟，没有对错答案，会做脱敏处理。

## 1. 基本情况（5 min）

1. 你现在几年级？最近一次数学大考/期中成绩大概在什么水平（如班级排名区间）？
2. 你目前觉得数学学习中最花时间、最头疼的环节是哪个？（记笔记 / 听课 / 做题 / 订正错题 / 复习）

## 2. 学习场景与习惯（10 min）

3. 请回忆最近一周，你具体在哪几个场景里"需要别人帮你讲题"？（作业 / 备考 / 预习 / 考前突击…）
4. 遇到不会的题，你通常会怎么做？最先想到求助谁？（老师 / 同学 / 搜题 App / AI 工具 / 放弃）
5. 你使用过哪些搜题或 AI 解题工具？（小猿搜题 / 作业帮 / Photomath / Khanmigo / 豆包 / 文心一言 / ChatGPT…）频率如何？
6. 在什么情况下你会"只看答案、不想看过程"？什么情况下你"特别想看过程"？

## 3. 现有工具体验（15 min）

7. 用一个具体例子：最近一次你用 AI/搜题工具讲一道题，整体体验如何？请把过程从头到尾讲一遍。
8. 你觉得它讲得好/不好的地方分别是什么？
9. 有没有遇到过"它给的答案是对的，但过程跳步、你看不懂"的情况？后来怎么解决的？
10. 有没有遇到过"你按自己的思路写，它却只给标准答案、不知道你错在哪"的情况？
11. 你更希望工具直接给答案，还是引导你自己想出来？为什么？

## 4. 核心痛点深挖（10 min）

12. 在"看不懂过程""没法按我的思路纠错"这两类问题中，哪个更影响你的学习效果？能否举一个印象最深的例子？
13. 如果你可以把一个"错题本"交给 AI 管理，你最希望它帮你做什么？（错因归类 / 同类题推送 / 定期复习提醒…）
14. 你愿意为"讲得明白、能纠错"的工具付出什么？（下载 / 注册 / 付费 / 录制错题照片…）

## 5. 期望与想象（10 min）

15. 如果有一款理想的 AI 数学助手，你希望它长什么样？请描述一个你想象中的完美体验片段。
16. 你希望它以什么形式出现？（网页 / App / 微信小程序 / 浏览器插件…）
17. 对"拍照识题"“分步讲解”“错因分析”三个功能，按你的需要程度排序，并说明理由。
18. 你担心 AI 讲题会带来什么坏处？（依赖 / 抄袭 / 讲解错误…）

## 6. 收尾（5 min）

19. 还有没有想补充的？访谈结束后如果你愿意，可以加入后续内测（10 人），我们会提供 Demo 供你试用并收集反馈。

## 访谈记录编码规则（用于内部整理）

| 编码 | 含义 |
| --- | --- |
| S/场景 | 使用场景（作业、备考、预习、错题订正、竞赛…） |
| P/痛点 | 高亮痛点点（跳步、看不懂、不纠错、不按思路…） |
| W/需求 | 用户期望的功能点 |
| C/竞品 | 用户提及的竞品与评价 |
| Q/付费 | 付费意愿与方式 |

> 每份访谈记录用 `受访者编号_年级_日期` 命名（如 `U03_高一_0912`），并完成关键词编码表。

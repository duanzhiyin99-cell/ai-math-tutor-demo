# 04 需求优先级列表（RICE 打分）

> RICE = (Reach × Impact × Confidence) / Effort
> - **Reach**：每季度覆盖的目标用户量（按"周活跃用户数"估计，单位：人/季度）
> - **Impact**：对单个用户的影响（0.25 少量 / 1 中等 / 2 高 / 3 极大）
> - **Confidence**：信心系数（80%+ = 1.0，60–80% = 0.8，40–60% = 0.5）
> - **Effort**：团队（1 PM + 1 前端 + 1 算法）所需人周数

## 三、优先级划分（MVP 范围）

| 优先级 | 需求 | 是否进入 MVP |
| --- | --- | --- |
| **P0（MVP 必做）** | R2 分步讲解、R1 拍照识题、R3 错因分析 | ✅ 进入 MVP |
| **P1（MVP 加分项）** | R4 讲解深度三档、R6 同类题推荐、R8 答案折叠 | ✅ 进入 MVP（低成本高感知） |
| **P2（V1.1）** | R5 苏格拉底引导、R7 错题本 | ⏳ 下一版本 |
| **P3（V1.2+）** | R9 知识点图谱、R10 多端形态 | ⏳ 远期 |

## 四、排序说明

1. **R2 分步讲解**是最大痛点（P1 提及率 93%）且实现成本可控 → 得分最高；
2. **R1 拍照识题**是"入口刚需"（13/15），虽然算法成本高，但缺它则获客受阻 → 同列 P0；
3. **R3 错因分析**是本产品与"搜题软件"差异化的核心（P2 提及率 80%）→ P0；
4. **R8 答案折叠**成本极低、影响信任与合规 → 高性价比，列为 P1；
5. R5/R7 依赖算法与数据积累，MVP 阶段信心不足（0.5）且成本高 → 延后；
6. R9/R10 超出 MVP 范围，列为远期。

---

*得分解释：RICE 得分 = 9000×3×1.0÷2 = 13,500（R2），以此类推。Effort 为估算的人周数，随技术选型（LLM API vs 自建 OCR）会微调。*

# 03 用户画像（Persona）

> 基于 15 人访谈聚类，抽象出 3 类典型用户。画像用于指导功能优先级与交互设计。

---

## Persona 1：小航 —— 「作业救急型」

> "作业写不完了，我就想知道这道题到底怎么做的，别给我整一堆跳步。"

| 维度 | 内容 |
| --- | --- |
| 基本信息 | 男，15 岁，初三（U03/U05 聚类），数学成绩中等偏上 |
| 典型场景 | 每天 20:00–22:30 写作业，遇到压轴/中档题卡壳 |
| 行为 | 先自己算 10 分钟，不会就拍照搜题；偏好"直接讲"，偶尔看答案 |
| 痛点 | P1 跳步看不懂、P5 识别不准（手写草稿拍照） |
| 核心诉求 | 拍照→快速出分步过程，每步能展开"为什么"；识别后可编辑 |
| 付费意愿 | 30 元/月以内，家里有付费预算 |
| 一句话价值主张 | "今晚能把作业写完，而且是真的看懂了，不是抄答案。" |

---

## Persona 2：小雨 —— 「错题突破型」

> "同一类型的题我错了三遍，我想知道我的思路到底哪里出了问题，别再给我标准答案了。"

| 维度 | 内容 |
| --- | --- |
| 基本信息 | 女，17 岁，高二（U07/U09 聚类），数学成绩中等偏下，文科生 |
| 典型场景 | 周末整理错题本；考前一周集中刷同类题 |
| 行为 | 会写过程但经常在"移项/变号/配方"等细节翻车；用过豆包但觉得"答非所问" |
| 痛点 | P2 无法按自己思路纠错、P4 讲解不匹配水平 |
| 核心诉求 | 上传自己的错误过程→AI 定位错因→给出纠正示范→推荐 2–3 道同类题 |
| 付费意愿 | 愿意付费（10–20 元/月），但要求"真能对症下药" |
| 一句话价值主张 | "让 AI 当我的私人错题老师，把我反复错的类型彻底消灭。" |

---

## Persona 3：学长 —— 「概念钻研型」

> "我不只想要答案，我想知道这个定理是怎么来的，推导是不是严谨。AI 能不能别老跳步？"

| 维度 | 内容 |
| --- | --- |
| 基本信息 | 男，20 岁，大二（U11/U13/U15 聚类），工科专业 |
| 典型场景 | 课前预习高数/线代；做作业遇到概念不清；备考期末 |
| 行为 | 使用 Wolfram Alpha / ChatGPT；对过程严谨性要求高 |
| 痛点 | P3 缺"为什么"、P1 跳步（尤其高数推导）、P4 模板化 |
| 核心诉求 | 完整推导、概念讲解、可追问"为什么这里能这样变"；支持 LaTeX |
| 付费意愿 | 愿意订阅（20–30 元/月） |
| 一句话价值主张 | "帮我建立严谨的数学直觉，而不只是记住公式。" |

---

## 画像→设计原则映射

| 原则 | 说明 | 对应画像 |
| --- | --- | --- |
| 1. 一步都不能省 | 默认展示完整步骤，每步可折叠/展开"为什么" | 小航、学长 |
| 2. 顺着学生的思路纠错 | 支持上传错误过程/答案，错因定位到具体步骤 | 小雨 |
| 3. 讲解深度可调节 | 基础/标准/进阶三档 + 引导模式 | 小航、小雨、学长 |
| 4. 拍照识别可编辑 | 识别结果允许手动修改，支持 LaTeX | 小航 |
| 5. 防依赖设计 | 答案可折叠、"先想再看"引导、合规提示 | 全体（尤其初中生） |

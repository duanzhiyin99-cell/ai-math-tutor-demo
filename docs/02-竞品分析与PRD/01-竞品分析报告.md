# 01 竞品分析报告：Khanmigo / 豆包 / Photomath

> 分析维度：定位、核心功能、解题交互设计、优点、短板、对我们的启示。
> 分析时间：2025.10。

---

## 一、竞品概览

| 维度 | Khanmigo（可汗学院） | 豆包（字节跳动） | Photomath |
| --- | --- | --- | --- |
| 定位 | 教育场景 AI 导师（K12 为主） | 通用 AI 助手（含学习场景） | 拍照解题工具（数学为主） |
| 收费 | 订阅制（约 $4/月） | 基础免费 + 增值 | 基础免费 + Photomath+ 订阅 |
| 核心能力 | 苏格拉底式引导、教师看板、分步讲解 | 多模态问答、拍照、文本生成 | 拍照识题、分步求解、手写识别 |
| 平台 | Web / iOS / Android | App / 网页 / 插件 | iOS / Android / Web |
| 数学覆盖 | 小学~大学预科 | 全学段（质量不稳定） | 小学~大学（偏计算） |

## 二、解题交互设计对比（重点）

### 2.1 Khanmigo —— "引导式导师"

- **交互范式**：不直接给答案，通过连环提问引导（"你觉得下一步该怎么做？"），把选择权交给学生。
- **优点**：最能体现"教方法"；有教师/家长监控，防作弊合规做得好。
- **短板**：引导过程冗长，"作业救急"场景效率低；中文化不足；国内访问门槛高。
- **对我们的启示**：**引导模式值得做，但必须提供"快速讲题"开关**，按场景切换。

### 2.2 豆包 —— "通用助手 + 多模态"

- **交互范式**：对话式，支持拍照上传图片，用视觉模型识别题目后直接作答；回答自由度高。
- **优点**：入口轻、多模态强、交互自然；免费；能处理"抽象概念问答"。
- **短板**：**解题过程经常跳步、不稳定**；不能按学生上传的"错误过程"定位错因；对步骤严谨性无保证；易被当作抄答案工具。
- **对我们的启示**：通用助手缺少"教育约束"（跳步、不纠错、无难度适配）——这正是我们的机会点。

### 2.3 Photomath —— "拍照计算器"

- **交互范式**：拍照 → OCR 识别 → 展示"步骤列表 + 简要解释"，支持手写识别与图形题。
- **优点**：识别准确率高、步骤展示直观、加载快；付费版有额外讲解。
- **短板**：**讲解"机械化"**，多为"这是什么定理"，缺少针对个人错误的纠正；对中文教材/国内考点适配弱；无苏格拉底引导。
- **对我们的启示**：**"识别准确 + 步骤清晰"是基本功**，必须做到位；差异化在于"错因分析 + 思路跟随"。

## 三、能力对比矩阵（针对本项目核心场景）

| 能力 | Khanmigo | 豆包 | Photomath | **本产品（目标）** |
| --- | --- | --- | --- | --- |
| 拍照识题 | 弱（文本为主） | 中 | **强** | 强（识别后可编辑） |
| 分步讲解 | 中（引导式） | 弱（跳步） | 中（模板化） | **强（完整+每步"为什么"）** |
| 按学生思路纠错 | 部分 | **无** | **无** | **强（错因定位到步骤）** |
| 讲解深度调节 | 弱 | 无 | 弱 | **三档可调** |
| 同类题推荐 | 中（Khan 题库） | 无 | 无 | 强（错一练三） |
| 防依赖/合规 | **强** | 弱 | 弱 | 强（答案折叠等） |
| 中文教材适配 | 弱 | 中 | 弱 | **强** |

## 四、机会点与差异化定位

1. **空白地带 = 按学生思路纠错**：三大竞品均未解决"学生上传自己的错误过程→定位错因→纠正"这一场景 → 本产品核心差异点。
2. **教育约束 = 不跳步 + 讲原理**：通用助手（豆包）跳步、Photomath 机械化，而学生最痛的是"看不懂过程" → 本产品把"完整步骤 + 每步为什么"作为默认体验。
3. **场景化切换 = 救急/刷题/预习三模式**：Khanmigo 引导虽好但太慢，本产品提供"快速讲题 / 错因分析 / 引导模式"三档切换。
4. **国内教材与考试适配**：覆盖人教版/高考/考研等考点与常用术语，优于 Khanmigo/Photomath 的中文适配。

## 五、结论

> **定位一句话**：做一款"**看得懂、能纠错、不跳步**"的 AI 数学学习助手——比通用 AI 更懂教育，比搜题工具更懂"人"。
>
> MVP 以 Photomath 的"拍照识别"为入口基本功，以 Khanmigo 的"引导式教学"为高阶目标，以"**错因分析**"作为第一差异化卖点。

# Figma 原型导入指南 + 设计规范

> 本目录下的 SVG 都是**矢量文件**，导入 Figma 后是**可编辑图层**（不是不可改的图片），可以直接改文字、颜色、圆角。

---

## 一、怎么导入 Figma（3 步）

1. 打开 Figma → 新建一个 Design File（草稿即可）；
2. 把本目录里的 SVG 文件**直接拖进画布**（或菜单 File → Import）；
3. 每个 SVG 会变成一个 Frame（375×812，移动端尺寸）。

**建议顺序**：先拖 `01-低保真线框图.svg` 确认信息架构 → 再拖 5 个高保真文件 → 用 `00-原型总览-全流程.svg` 做作品集封面/一页展示。

> 如果导入后字体不是你的系统字体：全选 → 右侧 Text 面板把字体改成 **PingFang SC**（或用团队规范字体）。颜色、布局不受影响。

## 二、画板与栅格

| 项目 | 规范 |
| --- | --- |
| 画板尺寸 | 375 × 812（iPhone X 逻辑分辨率），等比放大到 390×844 也可 |
| 左右安全边距 | 16px（所有卡片、按钮统一） |
| 栅格 | 8pt 栅格（间距用 8 / 12 / 16 / 24） |
| 卡片圆角 | 12px；按钮圆角 12px；标签（Chip）圆角 999px |
| 卡片描边 | 1px #E5E7EB |
| 阴影 | 轻阴影（0 1px 3px rgba(0,0,0,.08)），卡片不要用重投影 |

## 五、组件清单（建议做成 Figma Component）

| 组件名 | 说明 | 变体 |
| --- | --- | --- |
| `Header/App` | 顶部蓝渐变栏（Logo + 标题 + 模式标签） | 默认 / 带返回 |
| `Card/Default` | 白底 12px 圆角卡片 | 默认 / 高亮（蓝边） |
| `Chip/Topic` | 示例题、知识点标签 | 默认 / 选中 |
| `Button/Primary` | 主按钮（渐变蓝） | 默认 / Disabled / Loading |
| `Button/Secondary` | 描边按钮 | 默认 |
| `Step/Card` | 步骤卡（序号 + 标题 + 表达式 + "为什么"按钮） | 折叠 / 展开（含黄色说明块） |
| `Fold/Answer` | 答案折叠条 | 收起 / 展开 |
| `Card/ErrorCause` | 错因卡片（标签 + 说明 + 正确答案 + 建议） | 有错因 / 过程正确 |
| `Row/SimilarProblem` | 同类题行（题目 + 答案 + 讲解入口） | 默认 / 已完成 |
| `Input/Text` | 输入框（题目、我的过程） | 默认 / 聚焦 |
| `Upload/Dropzone` | 拍照上传区 | 空态 / 已选图 |

| 起点 | 交互 | 终点 |

| 首页 · 示例题 Chip | On Tap | 识别确认页 |
| 首页 · 上传区 | On Tap | 识别确认页 |
| 首页 · 开始讲解 | On Tap | 分步讲解页 |
| 识别确认 · 确认按钮 | On Tap | 分步讲解页 |
| 分步讲解 · 为什么 | On Tap | 切换（Change to）展开态 |

| 分步讲解 · 错因入口 | On Tap | 错因分析页 |

## 八、面试时怎么讲这套原型（30 秒）

> 我的原型不是先画视觉，而是先把**信息架构和关键交互**定下来：首页把"拍照识题"做成唯一最大入口，因为它是刚需；识别之后我特意留了"可编辑"这一步，因为手写识别不可能 100% 准；讲解页每步都挂一个"为什么"，这是调研里 93% 的人提到的痛点；答案默认折叠，是防止学生直接抄。最后错因分析单独做一屏，因为这是我和竞品最大的差异点。

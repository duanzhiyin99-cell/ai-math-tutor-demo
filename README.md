# AI 数学学习助手（AI Math Tutor）

> **中学生 / 大学生** 使用 AI 学习数学时，普遍存在"解题跳步、无法按学生思路纠错"等痛点。
> 本项目独立完成从 **用户调研 → 竞品分析 → PRD → 原型与 MVP → 验证迭代** 的产品全流程。

## 一、项目背景与目标

中学生在使用拍照搜题 / AI 解题工具时，常见的体验是"答案秒出、过程看不懂、错因不知道"。
本项目的核心命题：

1. **不跳步**：分步讲解，每一步都有"为什么"；
2. **跟着学生思路走**：学生输入自己的错误过程后，能定位错因并给出针对性的纠正与练习；
3. **从"给答案"升级为"教方法"**：支持苏格拉底式引导（逐步提问、让学生自己说出下一步）。

## 四、可交互 MVP Demo

`prototype/` 目录下是一套**零依赖、开箱即用**的 Web Demo（Node.js 原生 http 服务）：

- **拍照识题**：本地上传题目图片（支持示例题），自动识别题目文本；
- **分步讲解**：按"审题 → 建模型 → 求解 → 检查"生成可交互的分步过程，每步附"为什么"；
- **错因分析**：学生输入自己的答案/过程，定位错因（如符号错误、移项未变号等）并给出纠正与同类练习；
- **可接入真实 LLM API**：配置 `LLM_API_KEY` / `LLM_BASE_URL` 后自动切换到真实大模型推理（OpenAI 兼容协议）；未配置时使用内置规则引擎演示，保证离线可运行。

```bash
cd prototype
node server.js          # 默认 http://localhost:8080
# 可选：LLM_API_KEY=sk-xxx LLM_BASE_URL=https://api.openai.com/v1 node server.js
```

详见 [`prototype/README.md`](prototype/README.md)。

## 五、快速使用指引

1. 阅读顺序建议：`01-用户调研` → `02-竞品分析与PRD` → `04-原型说明` → `03-验证与迭代`；
2. 运行 Demo 体验核心功能：`node prototype/server.js` 后访问 <http://localhost:8080>；
3. 若需接入真实大模型：在环境变量中配置 API Key 与 Base URL（详见 Demo 内 README）。
